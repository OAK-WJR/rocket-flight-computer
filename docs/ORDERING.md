In R9 C303 sits at the bias-tap node, east of the line (R9_DECISIONS D-S4-02); its role below is unchanged. **What each land may take when fitted by hand on the bench** (never as a JLC line: each new code would be Extended, past REQUIREMENTS M3's 52-code limit):
  - **C303 (GNSS_RF_ANT): a capacitor only.** It sits on the 3.2 V antenna-bias node (L30's antenna end), so an inductor there shorts the bias: the limiter holds the current, but the antenna goes dark. Use a capacitor rated ≥ 6.3 V.
  - **C305 (GNSS_RF_IN): a capacitor only while R304 is 0 Ω**, for the same reason (R304 joins it to the bias node). It may take an inductor only once R304 is replaced by a series capacitor (U30's RF_IN is DC-blocked inside the module, u-blox DS note 18).
  - **C313 and C314 (radio): a capacitor or an inductor.** The radio line carries no DC (D31 is a bidirectional TVS); an 0402 inductor at C313 can serve as a DC bleed to GND for a DC-floating antenna (EBYTE manual §5.1 shows 330 nH at ANT; `pass2_electrical.md` §5–6).
  - **C304 (GNSS_ANT_GATE): a capacitor only, 1.0–2.2 nF**, 0402, X7R or C0G, ≥ 10 V (the node never exceeds VCC_RF, about 3.2 V), for example Samsung CL05B102KB5NNNC (1.0 nF, 50 V X7R, LCSC C14442) or CL05B222KB5NNNC (2.2 nF, LCSC C84703), the same series as C302; start with 1.0 nF, the value pass 2's loop model used (62° worst phase margin, `pass2_electrical.md` ELECTRICAL-01). Fit it only if the short test oscillates (section 5). Never an inductor or a short there: it holds Q30's gate at GND, so Q30 stays fully on, Q32 cannot lift the gate (no current limit) and LNA_EN cannot switch the antenna off; a resistor to GND weakens both in the same way.
