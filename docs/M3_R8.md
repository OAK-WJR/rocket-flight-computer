# M3-ASSY-R8: partial re-placement with planned-bus routing

R8 is R7's circuit, re-placed and re-routed from scratch around R7's qualified copper. The schematic changes only in
U1's pin map (27 pins) and one pull-up rail; the BOM is R7's line for line. The aim was the owner's: correctness and
every requirement first, then simple, robust routing. The plan is `m3_design/assembly_review/sources/r8_design/r8_plan.md`
(Strategy B); every design decision is in `sources/r8_design/R8_DECISIONS.md` (D1–D111, fix pass 1's D85–D96, fix pass 2's D97–D105, fix pass 3's D106–D109 and fix pass 4's D110–D111 included),
each with its basis.

- **Board:** `m3_design/assembly_review/m3.kicad_pcb`, SHA-256
  `cc044ea0922ff826df19af9d9726d92c096ab2b127025b55d123d8772e5fb4a7` (fix pass 4; review pass 1 reviewed the step-9 board
  `429b6db4…`, review pass 2 fix pass 1's `6600ef94…`, review pass 3 fix pass 2's `990c8040…` and review pass 4 fix

  46 × 118 mm, 4 layers. Netlist
