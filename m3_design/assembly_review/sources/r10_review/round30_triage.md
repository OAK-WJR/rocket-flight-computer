### R30-TRI-02 (Minor, doc; R30-SAFETY-02, R30-REQUIREMENTS obs 20). Board change: no
The first-article 70 C chamber test cannot pass as written: round 29 added 'LS120 <= 70 C' to its pass criterion, but in a 70 C chamber at the pad load every board part runs above chamber air (the same records put LS120 at 80-92 C), none of the listed failure remedies addresses LS120, so the 'interim' 55 C site limit could never be lifted; this contradicts owner row 36, which accepts LS120 as best-effort rather than a gate.

- **Evidence:** Reproduced from the text. REQUIREMENTS:94, M3_R10:496-497, ORDERING:608 and owner row 33 (R10_VALIDATION:2460) make the 55 C limit last 'until the first-article 70 C chamber test at the pad load passes (every 85 C part <= 85 C, and LS120 <= 70 C)'; owner row 36 (R10_VALIDATION:2427) states the pass as 'LS120 <= 70 C'. The same rows state the pad load (1.0-1.5 W, all on the board) gives +10-22 K over the bay, LS120 at about 80-92 C in a 70 C bay (Inference). Physically, with 1.0-1.5 W dissipated on the board in a 70 C chamber, LS120 (soldered at F(23,58.5), itself driven from 3V3) sits above 70 C in steady state on any board, so the clause fails by construction; the remedies ('a camera / port duty limit on the pad, or X7R parts on the same lands') do not change LS120's rating or its pad-load rise. Row 36 and AGENTS:21 treat LS120's hot end as accepted best-effort annunciation above about 48 C bay air, not as a gate. The requirements lens read the permanent 55 C limit as consistent; it is not, because every place calls the limit interim and the remedies imply the test can pass. Introduced by the round 29 fix pass (R29-TRI-04).
- **All places:** docs/REQUIREMENTS.md:94 (Temperature row); docs/M3_R10.md:496-498 (Hot-end temperature); docs/ORDERING.md:608 (8.3 Board temperature at the pad load); docs/R10_VALIDATION.md:2460 (owner row 33); docs/R10_VALIDATION.md:2427 (owner row 36, Needed column); m3_design/assembly_review/sources/r10_design/parts_qualification.md:40 (Round 29 note); STATUS.md:20 (LS120 hot end bullet); docs/R10_VALIDATION.md:2365 (R29-TRI-04 record row: history, add a pointer to R30-TRI-02).
- **Fix:** Text only, in every place listed: the pass criterion is 'every 85 C-rated part <= 85 C' alone. Replace the LS120 clause with: 'also record LS120's measured rise over chamber air at the pad load (thermocouple on LS120); LS120 is not a pass / fail gate: the bay-air limit above which buzzer annunciation is best-effort is 70 C minus that measured rise, which replaces the inferred 48 C (owner row 36)'.
